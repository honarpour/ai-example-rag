Retrieval-Augmented Generation end-to-end demo. Ask a question below and watch each stage of the pipeline light up: your question gets embedded, matched against a knowledge base of real documents, assembled into a prompt, and answered by AI grounded only in what it retrieved, not general knowledge.

How it works on AWS:
S3 (docs) → Lambda → Bedrock Titan Embeddings → S3 Vectors (k-NN search) → Bedrock LLM model

The local Python and Node servers are interchangeable, both proxy /api/ask, /api/upload, and /api/corpus to the same AWS backend.
